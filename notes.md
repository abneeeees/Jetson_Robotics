## Line detection
- Our first task is to detect lines from a given image of a solar panel
- There are several algorithms for line detection, including Hough Transform and Sliding Window

## Canny Edge Detector with the Hough Line Transform.
- The Canny Edge Detector with the Hough Line Transform is a combination of the Canny Edge Detector and the Hough Transform
- It works by first detecting edges in the image using the Canny Edge Detector, and then using the Hough Transform to detect lines in the edge image
